# Ubuntu-Edtech

An EdTech platform rooted in Ubuntu philosophy, delivered through app and web, pointing toward Afro-Futurism — Pan-African from launch.

## Overview

Ubuntu-Edtech is a concept and strategy repository for an education platform designed around three core ideas:

- **Ubuntu as pedagogy** — learning is grounded in community, shared growth, and collective responsibility.
- **Afro-Futurism as vision** — the platform is designed to imagine and build African futures through culturally rooted learning experiences.
- **App + web delivery** — the experience is intended to be accessible across digital touchpoints for learners, caregivers, educators, and partners.

The repository currently contains a client brief in HTML format that outlines the platform strategy, positioning, design direction, and programme concepts.

## Repository Contents

- `Ubuntu_EdTech_Client_Brief.html` — the main client brief and strategic presentation.
- `README.md` — repository overview and onboarding information.

## Key Themes in the Brief

The brief centers the platform around:

- **Pan-African learning experiences**
- **Ubuntu-led educational design**
- **Financial literacy and community learning**
- **CSR-linked programmes** such as:
  - **Feed a Mother**
  - **Help a Sista**
- **Support for both web and app-based experiences**
